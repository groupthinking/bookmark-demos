Parallel Decisions

Bookmark: RAG for decision models is here. This page posts your question to POST https://api.parallel.ai/v1/decisions through the Worker. The key stays in PARALLEL_API_KEY on the server.

Checking whether PARALLEL_API_KEY is set…
Question

Letters, numbers, underscores, and hyphens. Parallel returns the answer under this key.

State

Required by the API. An empty box is sent as {}.

Predicate criteria (optional)

Send both descriptions or neither. A noul answer is a probability from 0 to 1, not a boolean.

Choice options

2 to 255 options.

Score levels

2 to 10 levels. The score is the probability-weighted mean of the zero-based indexes.

Grounding options

Omitted when unused. An empty advanced_settings object is a 422 from Parallel, so this form does not send one.

Decision

No decision yet. Submitting with no key returns the missing-key error and no answer.
