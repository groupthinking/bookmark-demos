Agentic harness (one surface)

Bookmark: Karpathy's Agentic Engineering Finally Has Proper Tooling. This is a local demo harness — not Google Agents CLI, not ADK, not GCP. Spec → scaffold → grade → deploy (local registry) → trace, plus an autonomous plan/dispatch/measure/learn loop via the Worker API.

Autonomous loop
plan → dispatch → measure → learn → fix → continue

Spec — .agents-cli-spec.md

Edit tools, constraints, and success criteria. Persists in this browser (localStorage).

Scaffold — ADK-style tree

Creates real files under the workspace: app/agent.json, tools, eval config, skills doc. Python/ADK compile is untested; JSON config drives the demo runtime.

Grade — cases & scorecard

Generate cases from spec, grade with a deterministic rubric (not LLM-as-judge).

Deploy / register — local runtime

Registers the agent on an in-Worker registry (bookmark-demos-local). Registry memory is ephemeral on Cloudflare cold starts — re-deploy to invoke again. Google Agent Runtime, Cloud Trace, and Gemini Enterprise are untested (no GCP creds).
